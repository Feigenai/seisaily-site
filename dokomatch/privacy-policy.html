プライバシーポリシー

Dokomatch
制定日・最終更新日：2026年7月7日

Seisaily（以下「当方」といいます。）は、当方が提供するスマートフォンアプリケーション「Dokomatch」（以下「本アプリ」といいます。）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。本アプリをご利用いただく前に、本ポリシーの内容をご確認ください。

第1条（事業者情報）

運営者名：Seisaily（個人開発者）

連絡先メールアドレス：seisaily.com@gmail.com

提供地域：日本国内向けサービス

第2条（取得する情報および取得方法）

本アプリは、サービスの提供にあたり、以下の情報を取得します。

  1. Googleアカウント認証情報
    Firebase Authentication（Googleログイン）を通じて、メールアドレス、ユーザーID、Googleが提供する表示名を取得します。
  2. ユーザー登録情報
    利用者が本アプリ内で設定するニックネームを取得します。
  3. 利用データ
    ペアリング関係、スワイプ結果（気になる／見送る／誘ってみる）、マッチ履歴、解除券・ストリーク等の利用状況を、Cloud Firestore（Google Firebaseが提供するデータベース）に保存する形で取得します。
  4. プッシュ通知トークン（FCMトークン）
    通知配信のため、Firebase Cloud Messagingが発行するトークンを取得します。
  5. 広告識別子等
    Google AdMob（リワード広告）の提供にあたり、広告識別子（Android の Advertising ID／iOS の IDFA）等の情報がGoogle AdMobにより自動的に取得されます。

本アプリは、上記のほか、以下の情報は取得しません。

  • 位置情報
  • 連絡先
  • 通話履歴

なお、以下の情報は端末内でのみ処理・保存され、当方のサーバその他外部へ送信されることは一切ありません。

  • アプリ設定（端末内のローカル保存領域（shared_preferences）に保存）
  • フォトカード機能で利用者が撮影またはギャラリーから選択した写真（当該写真は端末内でのみ処理・保存され、当方のサーバを含むいかなる外部にも送信・保存されません。）

第3条（利用目的）

当方は、取得した情報を、個人情報保護法第17条に基づき、以下の目的の範囲内で利用します。

  1. 本人確認のため（Googleアカウント認証情報の確認）
  2. 本アプリのサービス提供のため（ペアリング機能、スワイプ機能、フォトカード機能等の提供）
  3. ペア相手とのマッチング処理のため
  4. プッシュ通知の配信のため
  5. リワード広告の配信のため
  6. サービスの品質改善・不具合分析のため
  7. 不正利用・不正アクセスの防止のため

取得した情報を、上記利用目的の達成に必要な範囲を超えて利用することはありません。利用目的を変更する場合は、本ポリシーの改定により利用者に通知します。

第4条（外部送信・第三者提供）

本アプリは、電気通信事業法における外部送信規律の趣旨を踏まえ、本アプリの利用に伴い情報を送信する外部の事業者、送信される情報、および利用目的を、以下のとおり開示します。

送信先事業者 提供モジュール 送信される情報 利用目的
Google LLC Firebase Authentication メールアドレス、ユーザーID、表示名 本人確認・ログイン機能の提供
Google LLC Cloud Firestore（Firebase） ニックネーム、ペアリング関係、スワイプ結果、マッチ履歴、解除券・ストリーク等の利用状況 サービス提供・マッチング処理・品質改善
Google LLC Cloud Functions（Firebase） マッチ生成処理に必要なユーザーID・スワイプ結果等 マッチング処理のサーバ側実行（不正防止のためのサーバ権威化）
Google LLC Firebase Cloud Messaging プッシュ通知トークン（FCMトークン） 通知配信
Google LLC Google AdMob 広告識別子（Advertising ID／IDFA）等の端末識別情報 リワード広告の配信・広告効果測定

各送信先の詳細については、以下の外部事業者のプライバシーポリシーもご参照ください。

  • Google プライバシーポリシー：https://policies.google.com/privacy
  • Firebase の利用とプライバシーの取り扱い：https://firebase.google.com/support/privacy
  • Google AdMob のプライバシーとセキュリティ：https://support.google.com/admob/answer/6128543

本アプリは、上記の第三者モジュール提供事業者への送信を除き、法令に基づく場合を除いて、取得した個人情報を利用者の同意なく第三者に提供することはありません。

第5条（広告について）

本アプリでは、Google AdMobが提供するリワード広告を利用しています。これに伴い、広告の配信および効果測定のため、広告識別子（Android の Advertising ID／iOS の IDFA）等の情報が自動的に取得され、パーソナライズド広告（利用者の興味・関心に応じた広告）が表示される場合があります。

利用者は、以下の方法により、広告識別子の利用（パーソナライズド広告の表示）についてオプトアウトすることができます。

  • Android：設定アプリ内「Google」＞「広告」から「広告のパーソナライズを無効にする」を選択、または広告識別子のリセットを行う
  • iOS：設定アプリ内「プライバシーとセキュリティ」＞「トラッキング」から本アプリのトラッキング許可をオフにする、または「App Tracking Transparency」の許諾ダイアログで「アプリからのトラッキングを求めないでください」を選択する

オプトアウトを行った場合でも、広告自体は表示されますが、パーソナライズされていない広告が配信されます。

第6条（ペア相手への情報共有）

本アプリは、2人のユーザーがペアを組んでお出かけスポットをスワイプし、マッチングを楽しむことを目的としたサービスです。そのサービスの性質上、以下の情報はペアリングした相手ユーザーに表示・共有されます。

  • ニックネーム
  • スワイプ結果（気になる／見送る／誘ってみる）
  • マッチ情報（成立したマッチの内容、マッチ履歴）

上記以外の情報（メールアドレス、ユーザーID等の認証情報や、端末内にのみ保存される写真等）がペア相手に共有されることはありません。

第7条（安全管理措置）

当方は、取得した個人情報の漏えい、滅失またはき損の防止その他の安全管理のため、以下の措置を講じます。

  1. 個人情報の取り扱いはFirebase（Google Cloud Platform上のインフラ）を利用し、通信の暗号化（TLS等）を行った上で送受信します。
  2. アクセス制御により、個人情報を取り扱う権限を必要最小限の範囲に制限します。
  3. 不正アクセス・不正利用を防止するため、サーバ側での権限検証（Cloud Functions等によるサーバ権威化処理）を実施します。
  4. 委託先（Google LLC等のインフラ提供事業者）の選定にあたっては、当該事業者のセキュリティ水準を考慮します。

第8条（保存期間と削除）

取得した個人情報は、第3条に定める利用目的の達成に必要な期間、または法令の定めに従い保存します。

利用者は、本アプリのアカウントを削除することにより、当方のサーバ（Firebase上）に保存されている自己の個人情報の削除を請求することができます。アカウント削除の請求は、以下のいずれかの方法により受け付けます。

  • アプリ内のアカウント削除機能（プロフィール画面の「アカウント削除」）からの操作
  • seisaily.com@gmail.com宛のメールによる削除請求

削除請求を受けた場合、当方は合理的な期間内に、法令上保存の必要がある情報を除き、当該利用者に関するサーバ上の個人情報を削除します。

第9条（開示・訂正・利用停止等の請求）

利用者は、当方が保有する自己の保有個人データについて、個人情報保護法の定めるところにより、開示、訂正、追加、削除、利用停止、消去または第三者提供の停止（以下「開示等」といいます。）を請求することができます。

開示等の請求を希望する場合は、seisaily.com@gmail.com宛にご連絡ください。当方は、本人確認を行った上で、法令の定めに従い合理的な期間内に対応します。なお、法令に定める例外事由に該当する場合は、開示等の請求にお応えできない場合があります。
